# Арена: Рикошет

## Сборка и текущий выпуск

Исходники интерфейса находятся в public, общая физика и награды — в physics.js.
Команда npm run build создаёт три автономных файла index.html, web.html и mobile.html.
Готовый комплект для публикации находится в папке «Релиз для GitHub Pages».
Все три файла содержат VK Bridge, физику, интерфейс и локальный сеанс. Дополнительная загрузка скриптов при открытии не требуется.

    npm ci
    npm run build
    npm test
    npm run test:browser

Для браузерной проверки используется установленный Microsoft Edge. На другой машине можно указать путь к Chromium через BROWSER_PATH.
Проверка создаёт временный браузерный профиль, тестирует размеры экрана, жесты, паузу, сохранение, серверный клиент и сигнал инициализации VK.

Одиночная сборка на GitHub Pages сохраняет прогресс на устройстве. Для опубликованных дуэлей и переноса профиля между устройствами потребуется развёртывание сервера, описанное ниже.
Экспортные папки формируются из исходников. Правки в них следует вносить через исходники и повторную сборку.

## Управление и пауза

В мобильном входе по умолчанию включено управление одним пальцем. Площадка под полем позволяет двигать отражатель, сохраняя обзор арены. Отпускание пальца запускает импульс, если он готов. Чувствительность настраивается в раскрывающемся разделе управления.

В режиме «По позиции» отражатель следует за мышью или касанием. Щелчок включает импульс. Также работают стрелки и пробел.

Кнопка «Пауза», сворачивание окна и событие скрытия приложения VK приостанавливают одиночную волну. Возобновление происходит по кнопке «Продолжить». Выход из волны требует подтверждения. В сетевой дуэли действует общий ход матча и правила переподключения.

Оранжевые ворота внизу принадлежат игроку. Бирюзовые ворота — цели. Появление новых шаров, голы и точные удары сопровождаются сообщениями, а кнопка удара показывает готовность и перезарядку.

Одноэкранная HTML5-аркада для VK Mini Apps. Клиент рисует объёмный стол средствами Canvas 2D. Node.js ведёт физику с фиксированным шагом 1/60 секунды, принимает положение отражателя и команду удара по WebSocket и сохраняет результаты в SQLite. Все участники дуэли имеют одинаковые характеристики.

## Локальная игра

Требуется Node.js 24. Из каталога проекта выполните:

    npm ci
    npm start

Откройте http://127.0.0.1:3000. Для проверки дуэли откройте второе независимое окно инкогнито, создайте комнату в первом и введите её код во втором. В демонстрационном режиме профиль привязан к гостевому идентификатору вкладки. Сервер слушает только loopback.

В волнах игрок защищает нижнюю сторону, ещё три стороны занимают боты. При пропущенном голе сторона теряет прочность. Через 35 и 70 секунд добавляются шары. Победа открывает следующую волну и повышает скорость ботов до установленного предела. При ничьей по оставшейся прочности на отметке 150 секунд игрок проходит волну. Дуэль завершается при семи голах или по счёту через 120 секунд, при равенстве — следующим голом. На переподключение даётся 30 секунд. При досрочном выходе из дуэли первые 15 секунд награды отключены.

Двигайте мышью, перетаскивайте отражатель пальцем или нажимайте стрелки. Направление отскока зависит от точки контакта. Для ускоренного удара нажмите пробел или кнопку перед касанием. Окно точности 170 мс, перезарядка 800 мс.

## Подключение к VK

Разместите один постоянно работающий процесс Node за HTTPS reverse proxy на том же домене, проксируйте WebSocket Upgrade для /play и укажите HTTPS-адрес в настройках игры VK. Для нескольких процессов потребуется общее хранилище комнат и маршрутизация сессий. Перезапуск процесса завершает активные матчи, записанные результаты сохраняются.

На сервере задайте VK_APP_ID, VK_SECRET и PUBLIC_ORIGIN (например https://arena.example без завершающего слеша). Установите постоянный случайный PROFILE_KEY до первого запуска, чтобы ротация секрета VK сохраняла привязки. DB_PATH должен указывать на файл на постоянном томе вне публичного каталога. PORT по умолчанию 3000. В рабочей среде задайте NODE_ENV=production для обязательной проверки конфигурации.

Сервер проверяет HMAC-подпись, ID приложения и возраст запуска, сохраняет псевдоним аккаунта, опыт, осколки, волну и рейтинг. Email, телефон и список друзей игре не требуются. Настройте HTTPS/WSS, права доступа к базе и резервным копиям, отключите запись строки запроса с launch-параметрами в логи прокси. В течение 10 минут подписанная ссылка позволяет повторный вход, поэтому её нельзя передавать сопернику. Для приглашения передавайте только код комнаты. После истечения этого окна для нового подключения нужно заново открыть игру в VK.

## Боковой баннер

В меню клиент запрашивает вертикальный Sticky banner с выравниванием вправо. 160 CSS-пикселей свободного места — внутренний порог попытки, размер креатива сообщает Bridge. Клиент сверяет фактические размеры с местом справа и скрывает неподходящий формат. При узком экране запрос пропускается. Перед созданием комнаты и стартом волны баннер скрывается. Нужны подключённая монетизация и проверка размещения в реальном приложении.

В приложении № 1 к [оферте VK](https://apiok.ru/apps/launch/documents/contract/adv/offer_new/) указано 17 ₽ за 1000 показов Sticky banner и 25 ₽ для Native Sticky banner, без НДС. Доход считайте по зачтённым показам и формату из отчёта подключённого приложения. [Параметры официального Bridge](https://github.com/VKCOM/vk-bridge/blob/master/packages/core/src/types/data.ts).

## Проверка

    npm test

Тесты используют отдельную БД в памяти и тестовую подпись. Проверяются удар, гол, овертайм, мультибол, доступ к публичным файлам, отказ при неверной подписи, дуэль двух клиентов, переподключение и получение награды с нового устройства. Перед публикацией нужны испытания на iOS, Android и в веб-клиенте VK, при задержках и на реальной рекламе. Магнит, магазин, сезоны и турниры относятся к следующим версиям.
